GastroBar POS — Sistema de Autenticación, Dispositivos Autorizados y Sesión Única

Versión 2.0 (Producción)

1. Diagrama de Flujo de Autenticación y Validación de Acceso

1
👤 Intento de Inicio de Sesión (Login)
El usuario ingresa credenciales (PIN o Usuario/Clave). El cliente adjunta el token criptográfico del dispositivo (x-device-token).
2
👑 Evaluación de Roles Exentos (Admin / Developer)
Si el usuario es Administrador o Desarrollador, obtiene acceso total inmediato desde cualquier red o dispositivo sin restricciones.
3
🌐 Capa 1: Filtro de Red por IP Pública
Para roles operativos, el servidor valida que la IP pública coincida con la configurada en el bar. Si no coincide, rechaza con HTTP 403.
4
📱 Capa 2: Lista Blanca de Dispositivos Autorizados
Verifica que el device_token esté registrado y activo en DispositivosAutorizados. Si no lo está, bloquea y abre modal para vincular con PIN de Admin.
5
⚠️ Capa 3: Sesión Única Activa (Bloqueo de Segundo Login)
Si el usuario ya tiene sesión abierta en otro dispositivo, el servidor rechaza el nuevo acceso con HTTP 409 Conflict y muestra la terminal previa. El administrador puede liberar la sesión con su PIN.
6
✅ Acceso Concedido
Carga la interfaz operativa (caja, salón, cocina, barra) con conexión segura y monitorizada.

2. Las Tres Capas de Protección Integral

🌐
1. IP Pública del Bar
Bloquea intentos de inicio de sesión fuera de las instalaciones del bar (casas, conexiones celulares externas).
📱
2. Dispositivos Autorizados
Solo las tablets, PCs y celulares autorizados por el administrador pueden operar el sistema, evitando accesos desde celulares de clientes.
⚠️
3. Sesión Única (Bloqueo)
Impide que dos personas compartan una misma cuenta. Si se intenta abrir la cuenta en otro equipo, se bloquea el acceso hasta que se cierre en el anterior o se libere con PIN de Admin.

4. Guía Rápida para el Administrador

Para gestionar la seguridad del negocio:

  1. Ingrese como Administrador y abra el menú ⚙️ Administración ➔ 🌐 Seguridad & Red del Local.
  2. Active o desactive los interruptores según la necesidad del negocio.
  3. Consulte la lista de terminales registradas, asigne nombres identificativos y revoque accesos con el botón 🗑️ cuando un equipo sea retirado o reemplazado.
  4. Si un empleado no puede ingresar porque su sesión quedó abierta en un dispositivo sin batería o extraviado, use el botón "Desconectar Sesión Previa" e ingrese su PIN de Admin para liberarla al instante.
